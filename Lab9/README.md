# Lab 9 – Tables with Headers and Footers

## Objective
To understand HTML tables and learn how to organize tabular data using captions, headers, body sections, footers, and accessibility attributes.

## Tasks

### Task 1 – Basic Marks Table
- Created `marks.html`.
- Added a table caption: Marks of Class A.
- Used `thead` for column headings.
- Used `tbody` to display student marks.
- Added Maths and Science marks for students.

### Task 2 – Table Footer
- Created `marks-average.html`.
- Added a table footer using `tfoot`.
- Displayed class averages for Maths and Science.
- Used the same table caption and column headings.

### Task 3 – Accessible Table
- Created `marks-accessible.html`.
- Used `scope="col"` for column headers.
- Used `scope="row"` for student name headers.
- Improved table accessibility and structure.
