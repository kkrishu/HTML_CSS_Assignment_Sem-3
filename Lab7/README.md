# Lab 7 – About Me Page

## Objective
To create a basic personal webpage using semantic HTML elements, navigation links, sections, and email links.

## Tasks

### Task 1 – Basic Page Structure
- Created `about-me.html`.
- Added a header containing a heading with the student's name.
- Added navigation links for About and Contact.
- Created empty main and footer sections.

### Task 2 – About Section
- Added an About section inside the main element.
- Used an ID attribute for the section.
- Added a heading and an introductory paragraph.

### Task 3 – Contact Section
- Added a Contact ID to the footer.
- Added a paragraph containing an email link.
- Used the `mailto:` scheme to create the email hyperlink.
