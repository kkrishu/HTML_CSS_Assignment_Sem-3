# Lab 13 – Flexbox Layouts

## Objective
To learn CSS Flexbox and use its properties to create navigation layouts, align cards, and build wrapping layouts.

## Tasks

### Task 1 – Navigation with Flexbox
- Created `nav-flex.html`.
- Added four navigation links: Home, About, Events, and Contact.
- Used `display: flex` to arrange links horizontally.
- Applied a dark background and white link text.

### Task 2 – Centred Cards
- Created `centred-cards.html`.
- Created three cards: Starter, Standard, and Premium.
- Added prices to each card.
- Used `justify-content` and `align-items` to align the cards in a row.

### Task 3 – Wrapping Cards
- Created `wrapping-cards.html`.
- Added four stationery cards: Notebook, Pen, Bag, and Book.
- Used `flex-wrap` to allow cards to move onto new lines.
- Tested the layout by narrowing the browser window.
