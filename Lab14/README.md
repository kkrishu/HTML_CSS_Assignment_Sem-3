# Lab 14 – CSS Grid Layouts

## Objective
To understand CSS Grid and create equal-column layouts, responsive galleries, and dashboard layouts using named grid areas.

## Tasks

### Task 1 – Three-Column Grid
- Created `grid-first.html`.
- Added six numbered boxes.
- Used `display: grid` to create a grid layout.
- Used `repeat(3, 1fr)` for three equal columns.
- Applied a 12px gap between boxes.

### Task 2 – Responsive Gallery
- Created `gallery.html`.
- Added the heading Club Photo Gallery.
- Created six photo placeholder boxes.
- Used `repeat(auto-fill, minmax(150px, 1fr))` for responsive columns.
- Applied a 10px gap between gallery items.

### Task 3 – Dashboard Grid Areas
- Created `dashboard-areas.html`.
- Defined two columns of 200px and 1fr.
- Used `grid-template-areas` to arrange the layout.
- Placed the header and footer across both columns.
- Positioned the sidebar on the left and main content on the right.
