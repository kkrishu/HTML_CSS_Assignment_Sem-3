## Lab Assignments

| Lab No. | Assignment | Topics Covered |
|---|---|---|
| 01 | Starting a Git Repository | Git initialization, configuration and commits |
| 02 | Pushing and Cloning a Repository | Git remotes, pushing and cloning |
| 03 | Your First HTML Page | HTML structure, headings and text formatting |
| 04 | Divs, Attributes and a Small Fix | Div elements, attributes and HTML corrections |
| 05 | Links and Images | Hyperlinks and images |
| 06 | Types of HTML Lists | Ordered, unordered and description lists |
| 07 | About Me Page | Page structure, navigation and contact links |
| 08 | Sign-Up Forms and Choices | Forms, input fields and dropdowns |
| 09 | Tables with Headers and Footers | HTML tables and accessibility |
| 10 | CSS Fundamentals | Inline, internal and external CSS |
| 11 | Units and CSS Variables | CSS units and custom properties |
| 12 | Box Model, Cards and Scrolling | Box model, card styling and overflow |
| 13 | Flexbox Layouts | Flexbox alignment and wrapping |
| 14 | CSS Grid Layouts | Grid columns, galleries and grid areas |
| 15 | Responsive Pages with Media Queries | Responsive layouts, images and typography |
