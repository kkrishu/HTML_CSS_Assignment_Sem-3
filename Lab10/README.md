# Lab 10 – CSS Fundamentals

## Objective
To understand different methods of applying CSS, including inline CSS, internal CSS, external stylesheets, and CSS selectors.

## Tasks

### Task 1 – Inline and Internal CSS
- Created `inline-internal.html`.
- Applied inline CSS to change paragraph text colour.
- Used internal CSS to style the heading.
- Applied a background colour to highlighted text using a class selector.

### Task 2 – External Stylesheet
- Created `style.css`.
- Styled headings using an element selector.
- Used a class selector to italicize notes.
- Used an ID selector to underline the title.
- Set paragraph font size and text colour.

### Task 3 – Link an External Stylesheet
- Created `linked.html`.
- Connected the external `style.css` file using the link element.
- Applied the external styles to the heading and paragraphs.
