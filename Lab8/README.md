# Lab 8 – Sign-Up Forms and Choices

## Objective
To learn how to create HTML forms using input fields, labels, radio buttons, dropdown menus, and required attributes.

## Tasks

### Task 1 – Sign-Up Form
- Created `signup.html`.
- Added Full Name, Email, and Password fields.
- Connected labels with their respective input fields.
- Used the POST method and form action.

### Task 2 – Form Choices
- Created `choices.html`.
- Added gender selection using radio buttons.
- Added a course selection dropdown.
- Included Female, Male, BCA, and B.Tech options.

### Task 3 – Required Fields
- Created `signup-required.html`.
- Added Full Name and Email input fields.
- Used the `required` attribute for form validation.
- Added a placeholder and Submit button.
