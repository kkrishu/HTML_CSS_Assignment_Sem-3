# Lab 11 – Units and CSS Variables

## Objective
To understand CSS measurement units and learn how to create reusable design values using CSS custom properties.

## Tasks

### Task 1 – CSS Units
- Created `units.html`.
- Used pixel units to define element dimensions.
- Used percentage units to define relative width.
- Used `rem` to set paragraph font size.
- Applied background colours to the boxes.

### Task 2 – CSS Variables
- Created `variables.html`.
- Declared custom properties inside the `:root` selector.
- Defined main colour, accent colour, and page padding variables.
- Used the `var()` function to apply the variables.

### Task 3 – Design Tokens
- Created `tokens.css`.
- Defined reusable primary colour, accent colour, heading size, and spacing variables.
- Applied the variables to body and heading styles.
- Linked the stylesheet to the demonstration HTML page.
