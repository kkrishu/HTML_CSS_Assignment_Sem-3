# Lab 15 – Responsive Pages with Media Queries

## Objective
To learn responsive web design using CSS media queries, responsive images, and relative font-size units.

## Tasks

### Task 1 – Mobile-First Cards
- Created `mobile-first.html`.
- Added two cards inside a container.
- Used a column layout for smaller screens.
- Added a media query for screens 600px and wider.
- Changed the cards to a side-by-side layout on larger screens.

### Task 2 – Responsive Image
- Created `responsive-image.html`.
- Added an image from the local `images` folder.
- Used `max-width: 100%` to keep the image within its container.
- Used `height: auto` to maintain the image's aspect ratio.

### Task 3 – Responsive Text
- Created `responsive-text.html`.
- Set the body font size to `1rem`.
- Set the heading font size to `1.5rem` by default.
- Used a media query to increase the heading size to `2.5rem` on screens 600px and wider.
