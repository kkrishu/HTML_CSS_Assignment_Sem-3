## Objective
To understand and implement different types of HTML lists, including unordered, ordered, nested, and description lists.

## Tasks

- Used the `ul` element to create a shopping list.
- Added Notebook, Pen, and Bag as list items.

### Task 2 – Ordered and Nested Lists
- Created `canteen-menu.html`.
- Used an ordered list for the canteen menu.
- Added a nested list for sandwich options: Cheese and Vegetable.

### Task 3 – Description List
- Created `faq.html`.
- Used `dl`, `dt`, and `dd` elements.
- Added library-related questions and their answers.
