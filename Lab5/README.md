# Lab 5 – Links and Images

## Objective
To learn how to create links between HTML pages and display images using the image element.

## Tasks

### Task 1 – Link to Another Page
- Created `home.html`.
- Added a welcome heading and paragraph.
- Created a hyperlink to `portfolio.html`.

### Task 2 – Link Back to Home
- Created `portfolio.html`.
- Added a portfolio heading.
- Created a hyperlink to navigate back to `home.html`.

### Task 3 – Display an Image
- Created `portfolio-image.html`.
- Added an image from the `images` folder.
- Set the image width and height to 200 pixels.
- Added descriptive alternative text using the `alt` attribute.
