# Lab 12 – Box Model, Cards and Scrolling

## Objective
To understand the CSS box model, create styled card components, and control content overflow using CSS.

## Tasks

### Task 1 – CSS Box Model
- Created `box-model.html`.
- Created two boxes with the same width, padding, and border.
- Applied `box-sizing: content-box` to the first box.
- Applied `box-sizing: border-box` to the second box.
- Compared the difference in their total dimensions.

### Task 2 – Card Design
- Created `card.html`.
- Designed a card using a `div` element.
- Applied background colour, border, rounded corners, and padding.
- Added a heading and paragraph inside the card.

### Task 3 – Scrollable Content
- Created `scroll.html`.
- Created a container with a fixed height of 120px.
- Used `overflow: auto` to enable scrolling.
- Added five paragraphs inside the container.
